1. 快速入门

1.1 安装与启动

Tadado 提供 Windows 安装包（.exe）和便携压缩包（.zip / linux.tar.gz）。启动后程序常驻系统托盘，主窗口同步打开。所有数据存储在本地 SQLite 文件，无需联网、无需注册。

1.2 创建任务

在任务视图顶部的输入框中输入 Markdown 格式的任务：

- [   ] <2026-06-15 14:30> 完成使用手册编写 #文档

格式说明：

部分说明示例
- [ ]任务前缀 + 优先级（* 数量 0-3，越紧急越多）- [***]（紧急）
<截止日期 时间><YYYY-MM-DD HH:MM>，整个尖括号可选——日期和时间均可省略<2026-06-15 14:30>
任务标题必填，描述任务内容完成使用手册编写
标签# 开头，空格分隔，可选（# 前须有空格或行首才识别为标签）#文档
提示优先级通过 - [ ] 中 * 的数量表示：[ ]=普通、[* ]=关注、[** ]=重要、[***]=紧急。日期、时间均为可选——不写截止日期也可以创建任务。状态（待办/进行中/已完成/逾期）由软件自动管理，无需在 Markdown 中标记。

1.3 界面概览

Tadado 有三个视图，通过标题栏按钮切换：

视图用途
任务视图日常任务的增删改查
活动分析日历热力图、活动统计
任务管理批量操作、标签管理、归档

窗口为无边框设计，整条标题栏空白区域均可拖拽移动。支持 Windows 窗口贴靠（Aero Snap）：拖拽到屏幕左右边缘自动半屏停靠、拖拽到顶部最大化、Win+←→↑↓ 快捷键分屏。边缘 8px 区域可拖拽缩放窗口。标题栏左侧 App 图标点击可返回任务视图并清空筛选。

2. 任务视图

2.1 新建任务

  • 新建单任务 — 输入框输入 Markdown 后按 Enter，或点击标题栏 新建单任务
  • 新建多任务 — 点击标题栏 新建多任务，编辑器生成 3 行模板任务
  • 草稿模式 — 新建时输入框蓝色高亮，未保存的草稿可丢弃

2.2 任务列表

9 列表格展示：复选框 / 序号 / 创建时间 / 任务内容 / 截止时间 / 进度 / 状态 / 标签 / 归档。

  • 优先级渲染 — 整行背景色标识：红（紧急）→ 橙（重要）→ 绿（关注）→ 淡蓝（普通）
  • 状态徽章 — 待办（蓝）/ 进行中（橙）/ 已完成（绿）/ 逾期（红），彩色圆角徽章
  • 自动逾期检测 — 超过截止日期的未完成任务自动标记为"逾期"
  • 行选择 — 支持单行选中和 Ctrl/Shift 多选，选中任务红色加粗凸显
  • 分页 — 每页 20/50/100 条，默认 20
  • 已完成置底 — 已完成任务自动排到列表底部，设置中可关闭

2.3 编辑任务

方式一：双击编辑（快速）

  • 在任务列表中双击任务行，弹出快速编辑对话框
  • 直接编辑 Markdown 源码，右侧实时解析预览（优先级、日期、标题、标签）
  • 对话框显示任务创建时间，方便对照调整截止日期
  • 保存时自动校验截止时间不早于创建时间

方式二：右侧编辑面板（完整）

单击任务行，右侧弹出编辑面板：

  • Markdown 源码编辑 — 直接编辑原始 Markdown，右侧实时预览
  • 截止日期 — 日历选择器 + 时间选择器（精确到分钟）+ 快速计算按钮
  • 快速计算 — 一键设定截止日期，6 个选项平铺展示：今天 / 明天(+1天) / 本周日 / 一周后(+7天) / 本月末 / 下月今天(+1个月)，选中即时预览"标签 (日期 时间)"
  • 活动时间线 — 任务进展记录，支持追加新进度
  • 优先级 — 下拉切换紧急程度（紧急 / 重要 / 关注 / 普通）
  • 状态切换 — 下拉切换状态，切换至"已完成"进度自动设为 100
  • 分区选择 — 将任务迁移到其他分区

编辑后点击 保存 提交，删除 移除任务。

2.4 筛选与排序

  • 全文搜索 — SQLite FTS5 引擎，实时匹配中文和英文关键词（300ms 防抖）
  • 状态过滤 — 待办 / 进行中 / 已完成 / 逾期
  • 优先级过滤 — 紧急 / 重要 / 关注 / 普通
  • 排序 — 5 种模式：优先级 / 截止时间 / 创建时间 / 状态 / 标题，默认"优先级"
  • 已完成置底 — 所有排序模式下已完成任务自动排到列表底部，设置中可关闭此行为。组内已完成任务按完成时间倒序（最近完成的在最前）

2.5 右键菜单

在任务行上右键可快速：更改状态 / 更改优先级 / 调整分区 / 延后处理 / 中止 / 重启 / 删除 / 复制 Markdown。支持多选批量操作。

2.6 统计与速览

  • 状态徽章条 — 各状态任务计数（待办/进行中/已完成/逾期），点击快速筛选
  • 进度动态条 — 6 个时间段按钮（昨天/今天/上周/本周/上月/本月），展示最近活跃任务的最新进展
  • 速览轮播 — 自动轮播任务卡片（每 5 秒切换，每组最多 3 个），按优先级排序，已完成任务排在最末

速览栏过滤逻辑

任务列表按 创建时间 ≤ 该日上限 过滤。默认隐藏已归档任务；点击进度栏按钮后同步显示已归档任务，方便回溯历史。

3. 活动分析

3.1 日历热力图

12 个月 × 7 天 × 5 周的紧凑日历，颜色深浅表示每日活动量：

  • 悬浮单元格查看：日期、活动数、涉及任务、标签分布
  • 顶部 ◀ 年份 ▶ 切换年份
  • 下拉筛选特定标签的活动

3.2 标签浏览

标签云面板：有活动的标签默认勾选，活动数为0的标签不预选（可手动勾选），右侧显示对应活动内容，支持搜索过滤和导航栏逐条浏览。

3.3 活动报告

导出当前标签的活动记录为 Markdown / Excel / TXT。

4. 任务管理控制台

4.1 筛选面板

左侧面板提供：关键词搜索 / 状态过滤 / 优先级过滤。

4.2 批量操作

工具栏提供全选 + 导出（Markdown / Excel）+ 已选计数。通过右键菜单可对多选任务执行：

  • 更改状态 / 更改优先级 / 调整分区 / 延后处理 / 中止 / 重启 / 删除
注意批量删除和延后处理直接影响任务数据，操作前请确认选中范围。调整分区需验证目标分区密码。

4.3 标签管理

右侧面板展示当前分区所有标签及其使用次数：

  • 重命名 — 选中标签 → 输入新名称 → 全局自动更新
  • 合并 — 多选标签 → 选择目标 → 源标签替换为目标后删除
  • 搜索 — 实时过滤标签列表
  • 任务-标签联动 — 点击任务行，右侧面板自动加粗高亮该任务的标签；点击标签项，任务列表中含该标签的任务自动前置（再次点击取消前置）
  • 标签列悬浮提示 — 鼠标悬停在任务表格的标签列上，显示该任务的完整标签信息
注意标签合并不可撤销，操作前务必确认。

4.4 归档管理

  • 手动归档 — 点击 归档已完成 立即归档当前分区所有 DONE 任务
  • 清除已归档 — 点击 清除已归档 永久删除归档任务（需二次确认）

5. 分区管理

5.1 什么是分区

分区是独立的任务空间，不同分区的任务、标签互不影响。首次启动时自动创建 演示空间（含 15 个演示任务，覆盖全部优先级和状态），用户可自行创建更多分区。

5.2 切换分区

点击状态栏最左侧的分区名称（accent 色 ● 标记）→ 下拉菜单选择目标分区。当前分区以同色 ● 标记，菜单项与按钮样式统一。

5.3 密码保护

  • 在设置中为每个分区单独设置密码
  • 锁定分区后，切换到该分区需输入密码
  • 解锁状态仅内存保持，关闭程序后重置
  • 自动锁定 — 按分区独立设定空闲超时（1/5/10/30/60 分钟）

5.4 管理分区

在设置对话框的分区表格中：新建 / 重命名 / 设默认 / 设密码 / 归档配置 / 自动锁定配置 / 删除（分区内有任务时不可删除）。分区表格支持右键菜单快捷操作。

5.5 归档规则

  • 即时归档 — 归档阈值设为 0，任务标记"已完成"时立即从编辑视图隐藏（进度栏和活动分析仍可查看）
  • 延迟归档 — 归档阈值设为 1~9998，完成后 N 天午夜自动归档
  • 永不归档 — 归档阈值设为 9999
  • 追溯归档 — 切换分区或修改阈值为 0 时，自动归档该分区所有已完成任务
  • 取消归档 — 已归档任务改回非完成状态时，自动恢复可见

6. 系统托盘与提醒

6.1 托盘操作

  • 右键菜单 — 显示/隐藏窗口、新建单任务、新建多任务、AI 助手、退出
  • 双击图标 — 切换窗口显示/隐藏
  • 最小化 — 开启"最小化到托盘"后，最小化隐藏到托盘而非任务栏
  • AI 助手 — 一键启动专属 Claude Code / Codex 会话，自动加载 Tadado skill；**自动续接上次会话**（无记录则新建），无需手动选择；上下文超 80% 时菜单标注并 托盘提醒 /compact。单一 provider：配置 ai_assistant.provider 指定 claude 或 codex， 未配置时自动检测 claude 优先；未安装任一助手时菜单置灰不可用

7. 设置

7.1 外观

  • 主题 — 亮色（暖灰纸感）/ 暗色（Tokyo-night 系），视觉规范统一： 暖调靛青强调色、卡片分层软阴影、统一圆角标度
  • 最小化到托盘 — 开启后最小化按钮隐藏到系统托盘
  • 开机自动启动 — 开启后随系统自动启动 Tadado

7.2 任务列表

  • 每页条数 — 20 / 50 / 100
  • 默认排序 — 优先级 / 截止日期 / 创建时间 / 状态 / 标题
  • 已完成置底 — 开启后（默认），所有排序模式下已完成任务自动排在列表底部；关闭后与活跃任务混合排列
  • 热力图起始年份 — 日历热力图的数据起始年
  • 热力图配色方案 — 4 组配色可选

7.3 归档 / 分区管理

  • 分区表格 — 5 列：名称 / 默认分区 / 归档阈值(天) / 自动锁定(分) / 密码
  • 表头固定 — 分区超过 6~7 行时表格自动出现滚动条，表头始终可见
  • 工具栏 — + 新增 和 − 删除 按钮始终可见，选中行后显示"已选 N 个分区"
  • 归档阈值 — 双击单元格编辑。0=完成任务后即时归档，1~9998=完成后N天午夜归档，9999=永不归档
  • 自动锁定 — 双击单元格编辑空闲超时分钟数（默认 3 分钟）
  • 新增分区 — 点击 + 新增 创建新分区，名称列直接输入
  • 删除分区 — 选中分区后点击 − 删除，分区内有任务时阻止删除

8. 命令行与 AI 助手

8.1 什么是 tadado-cli

安装目录下的 tadado-cli.exe 是 Tadado 的命令行通道，可在终端中管理任务， 也是 Claude Code 等 AI 助手操作 Tadado 的入口。它与软件界面共享同一份数据：

  • 软件正在运行时 — 命令自动转发给正在运行的窗口执行，界面实时刷新
  • 软件未运行时 — 命令独立执行，直接读写同一数据库

8.2 常用命令

  • tadado-cli list [--status DONE] [--tag 工作] [--keyword 关键词] [--overdue] [--archived] — 查询任务
  • tadado-cli today — 今日摘要（逾期 / 今日到期 / 临近 / 进行中）
  • tadado-cli add "- [*] TODO <2026-08-20> 买咖啡 #工作" — 新建任务（Markdown 语法与界面一致）
  • tadado-cli done <任务ID> / tadado-cli edit <ID> --due 2026-08-25 — 完成 / 修改任务
  • tadado-cli rm --match 关键词 — 删除任务（先加 --dry-run 预览）
  • tadado-cli archive --all、tadado-cli tags --counts、tadado-cli partitions、tadado-cli export --fmt xlsx --out 任务.xlsx — 归档 / 标签 / 分区 / 导出
  • tadado-cli recurrence <ID> --rule +1w、tadado-cli reminder --enable --digest-time 09:00 — 周期任务 / 提醒设置

加 --format human 以表格形式输出；默认输出 JSON 供程序解析。完整命令说明： tadado-cli --help。

8.3 配合 AI 助手（Claude Code skill）

Tadado 附带 Claude Code skill 说明（项目 .claude/skills/tadado/）， 安装后即可用自然语言管理任务，例如：

  • "帮我看看今天有什么任务" — AI 调用 today 生成摘要
  • "明天下午加一个买咖啡的任务" — AI 转为 Markdown 行后 add
  • "把写周报标成已完成" — AI 定位任务后 done

AI 删除 / 归档前会先向你确认再执行。

9. 常见问题

Q: 窗口显示异常（空白、错位、无法拖动或贴靠失效）

  1. 关闭并重启应用
  2. 切换全屏再退出（标题栏右侧 ⛶ 按钮），窗口会重置到屏幕中央
  3. 若贴靠（Snap）功能失效，可点击全屏按钮再还原，刷新窗口样式状态

Q: 搜索不到任务

  1. 确认当前所在分区（状态栏左侧分区名）
  2. 检查筛选条件是否过严
  3. 确认任务未被归档（归档任务在编辑视图不显示）

Q: 已完成任务为什么不见了

  1. 检查归档阈值设置（设置 → 归档/分区管理）。默认 0 = 完成后即时归档，任务从编辑视图隐藏
  2. 在任务管理页面将归档状态切换为"已归档"可查看已归档任务
  3. 点击进度栏按钮（昨天/今天等）可回溯已归档的历史任务
  4. 活动分析页面不受归档影响，始终包含全部历史数据

Q: 已完成任务为什么在列表底部

  1. 这是 v0.2.2 新增的默认行为——已完成任务自动置底，让活跃任务始终在前
  2. 如需关闭：设置 → 任务列表 → 取消勾选"已完成置底" → 保存

Q: 如何备份数据

  1. 关闭 Tadado
  2. 复制 resources/tadado.data 到安全位置
  3. 恢复时将备份文件覆盖同名文件
  4. 配置文件位于 resources/config.json，可一并备份

Q: 程序无法启动

  1. 确认系统为 Windows 10 或更高
  2. 检查杀毒软件是否拦截
  3. 重新安装最新版本（覆盖安装不丢失数据）
